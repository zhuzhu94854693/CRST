As shown in Figure 1, CRST comprises four interconnected components: local relational representation, cross-modal relational discrepancy modeling, semantic prediction, and semantic transition reasoning. First, modality-aware local relational descriptors characterize neighborhood structures in the optical and SAR observations. Separate relational encoders transform these descriptors into normalized feature representations. Second, cross-modal feature discrepancies and relational evidence are integrated with semantic comparison cues to generate binary change predictions. Third, a shared semantic prediction head estimates the semantic distributions of the two observations. Finally, the Semantic Transition Reasoning Module models joint semantic transition probabilities and provides additional evidence to the change prediction branch.
